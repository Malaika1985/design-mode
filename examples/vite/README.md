# Vite example

A one-page app with the plugin wired in, used to try the overlay by hand.

```sh
npm install
npm run dev
```

Open the printed URL, click the palette button in the bottom right, then click
an element and write a comment. The entry is appended to
`design-comments.md` in this folder.

`design-mode` is linked from the repository root (`file:../..`), so changes to
`src/` show up after a dev server restart.
